30天学习计划

三级高频考点

01 数据采集与数据清洗

数据完整性、一致性、准确性；缺失值、异常值、重复数据；格式统一与质量检查。

02 数据标注与质量控制

文本、图像、语音、视频标注；标签体系；一致性；抽检；交叉复核；标注质量评价。

03 模型训练基础

训练集 / 验证集 / 测试集；监督学习与非监督学习；过拟合、欠拟合；参数与超参数。

04 模型效果评价

Accuracy、Precision、Recall、F1、混淆矩阵。理解不同业务目标下指标权衡。

05 模型优化与问题分析

样本不平衡、错误标签、数据漂移、阈值调整、特征质量、训练数据补充。

06 安全、伦理与法规

数据安全、个人信息保护、知识产权、职业道德、网络安全与合规使用。

重点公式

指标公式
PrecisionTP / (TP+FP)
RecallTP / (TP+FN)
F12PR / (P+R)
Accuracy(TP+TN) / 全部

记忆：Precision 看“预测为正的有多少是真的”；Recall 看“真实为正的有多少被找出来”。

每日练习题

实操模拟

案例：某二分类模型 Accuracy=92%，Precision=80%，Recall=62%。

答题思路：

  1. Accuracy 较高，但不能单独说明模型表现优秀。
  2. Recall 仅 62%，说明正样本漏识别较明显。
  3. 优先检查类别不平衡、阈值设置、训练样本覆盖和标注质量。
  4. 如果业务更关注“不要漏掉正样本”，应优先提升 Recall，同时观察 Precision 与 F1 的变化。
